# ⚛️ React + Vite + TypeScript Template

A modern starter template with:

- ⚡️ [Vite](https://vitejs.dev/) – Fast bundler
- 📘 [TypeScript](https://www.typescriptlang.org/) – Strongly typed JS
- 💨 [Tailwind CSS](https://tailwindcss.com/) – Utility-first styling
- 🧩 [shadcn/ui]() – Beautiful, customizable UI components

---

## 🚀 Quick Start

```bash
git clone https://github.com/mohitprajapat2001/portfolio-web.git
cd portfolio-web

# Install dependencies
npm install

# Start the dev server
npm run dev
```

## ✅ Features

- 💅 Tailwind + shadcn/ui preconfigured
- 🎨 Material UI fully integrated with custom themes
- 🧠 React best practices (folder structure, separation of concerns)
- ✨ Prettier + ESLint for code formatting and linting
- 🔎 Supports both **dark/light themes** out of the box

## 🎨 Customize UI

```bash
npx shadcn-ui@latest add button
```
